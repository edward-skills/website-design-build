# Section 规格

用于复杂视觉、交互或需要交接的区块；普通区块可仅记录变更点。

- 区块名称 / 页面 / 语言：
- 目的：访客的问题、需要理解的信息、下一步动作。
- 依据：最新设计节点、资料与实际产品来源。

## 内容

- 标题与必要说明：
- 图片 / UI / 证据及其版本：
- CTA 文案、前置状态与真实目标：

## 构图与布局

- 主次关系、文字与画面比例：
- 容器宽高策略、gap、padding、最小 / 最大尺寸：
- 子元素分组、定位基准、裁切与溢出：
- 真实操作区域与装饰画面的边界：
- 手机采用缩放 / 重排 / 简化的对象与规则：
- 长文案及其他语言的处理：
- 用户手调只涉及哪些属性，哪些已确认尺寸 / 比例继续保留：
- 一组场景的共用布局语法、稳定标识与各自对应素材：

## 行为与运动

- 初始、hover / focus、选中或展开状态：
- 点击、键盘、触摸与滚动：
- 动效对象、变化参数、时序及保持不动的部分：
- 结束、取消、返回与减少动态效果：
- 如有数据：来源、空 / 加载 / 失败 / 成功状态。

## 验收

- 要检查的设备 / 语言 / 状态：
- 视觉判断点：
- 行为和真实结果：
- 与其他页面或区块的同步位置：
